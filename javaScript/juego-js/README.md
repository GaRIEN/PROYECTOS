# 🕹️ **Mini Juego en Canvas **


## 📌 **Descripción del Proyecto**

Este es un pequeño juego desarrollado en JavaScript que utiliza un canvas para renderizar un mapa en 2D. El objetivo es mover al personaje principal a través de distintos niveles, evitando enemigos y alcanzando el objetivo para ganar.

---

## 🎯 **Características Principales**

- Inicia con 3 vidas.
- Si colisionas con un enemigo, pierdes una vida.
- Si alcanzas el objetivo (🎁), avanzas al siguiente nivel.
- Si pierdes todas las vidas, el juego reinicia desde el primer nivel.
- Se guarda el mejor tiempo en localStorage.

---

## 🚀 **Tecnologías Usadas**

### 📌 **Frontend**
- HTML5, CSS3  
- JavaScript (Canvas API)
